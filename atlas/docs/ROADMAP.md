# Atlas Roadmap

This roadmap is ordered by dependency, not by excitement.

---

# Phase 0 — Foundation

**Goal:** Create the project skeleton.

* [ ] Repository
* [ ] Build system
* [ ] Project architecture
* [ ] Documentation
* [ ] Development workflow

**Definition of Done**

The project compiles and has a stable structure.

---

# Phase 1 — Engine

**Goal:** Build the minimal world.

* [ ] Window
* [ ] Camera
* [ ] Input
* [ ] Scene
* [ ] Basic rendering

Definition of Done:

A user can move through a simple world.

---

# Phase 2 — Workspace

Goal:

A developer can work inside Atlas.

Tasks:

* [ ] Terminal
* [ ] File explorer
* [ ] Basic text editor
* [ ] Project loader

Done:

A repository can be opened and explored.

---

# Phase 3 — Development Tools

Tasks:

* [ ] Git integration
* [ ] Build commands
* [ ] Run commands
* [ ] Logs
* [ ] Debug console

Done:

Software can be developed from inside Atlas.

---

# Evergreen Rules

* Finish one phase before beginning the next.
* Keep the project runnable at all times.
* Refactor only when it simplifies the system.
* Avoid adding features without a concrete use case.
* Prefer working software over ambitious plans.

---

# North Star

At any point, if priorities become unclear, return to this question:

> "What is the smallest improvement that makes Atlas a better environment for humans and AI to build, learn and discover together?"
